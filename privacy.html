隐私政策 (Privacy Policy)

速云梯（Suyunti Cloud）高度重视每一位用户的隐私安全与个人数据保密。本隐私政策向您郑重说明我们对于用户数据的处理原则与严格的技术保护标准。

严格的零日志记录承诺 (Strict No-Logs Policy)

我们在此作出最清晰、最明确的庄重声明：速云梯绝对不记录、不追踪、不存储任何用户的网络活动日志！ 具体包括但不限于：

  • 不记录浏览历史：我们绝不监控或记录您所访问的任何目标网站域名、网页 URL 或应用通信内容；
  • 不记录原始 IP 地址：我们不保留您连接到我们中继节点时的真实来源 IP 地址；
  • 不记录 DNS 查询：所有 DNS 解析均由我们本地内存级安全加密解析器处理，不向第三方泄露亦不保留解析记录；
  • 不存储通信数据：所有经过节点中继的流量均为加密转发，内存实时即时擦除，不落盘存储。

仅收集的基础账户信息

为保障基本的服务开通与技术计费正常运转，我们仅收集并妥善加密保护以下最少必要信息：

  • 注册所用的电子邮箱地址（仅用于账号登录、密码找回与核心业务通知）；
  • 订阅套餐类型、有效期及当月总计流量消耗量（仅用于配额结算，与访问内容完全脱钩）。

数据安全与加密技术

我们采用国际前沿的对称加密与强认证握手算法保护传输通道，节点服务器采用纯内存运行架构（RAM-Only Server Architecture），任何物理断电或重启均会自动销毁全部运行时数据，技术上从物理根源上彻底阻绝数据泄露的可能。

第三方披露原则

我们绝不将任何用户信息出售、租用或交换给任何广告商、数据分析机构或商业第三方。我们始终为您的网络自由与数字隐私构筑坚不可摧的坚盾。
